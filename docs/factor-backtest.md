# 五因子权重回测

`portfolio/factors.py` 里的 25/25/20/15/15 曾经是拍出来的，`ENABLE_FACTOR_SCORING`
也因此默认关闭 —— 理由写的是「一个看起来很量化却没验证过的公式，比一条诚实好读的规则更糟」。
这份文档把「没验证过」换成验证结果。

复现：

```bash
PYTHONPATH=src .venv/bin/python scripts/backtest_factors.py \
  --markdown docs/factor-backtest-raw.md      # --refresh 重新拉行情
```

方法、以及这套方法看不见什么，都写在 `scripts/backtest_factors.py` 的模块 docstring 里。
下面的数字来自 2026-09-01 那次运行。

## 口径

| 项 | 取值 |
|---|---|
| 候选池 | `data/universe.json` 的 872 只权益（A 800 / 港 32 / 美 40） |
| 行情 | 腾讯日 K，每只 800 根（约 3.2 年），前复权 |

回测一个跟线上略有出入的公式，量的就是另一个策略。

## 结论

**`ENABLE_FACTOR_SCORING` 保持默认关闭。** 理由从「没回测过」变成「回测了，没赢」：
在它真正要替换的那条路径上，五因子打分比市值规则**每月少 4 个基点，t = −0.09**。
最好的一组对照（去掉动量）也只有每月 +21 个基点、t = +0.47 —— 而这还没扣调仓成本。
一个 50 只的月度调仓组合不是免费的，赢不过换手成本的策略没有赢。

三条比结论本身更有用的读数：

1. **全截面 IC 为正，切到前 50 只就没了。** 组合打分在 872 只上的 rank IC 是 +0.059、t = 2.38，
   看着挺像回事；可一旦过完市值下限、再按 60/20/20 配额只留 50 只，优势归零。
   排序能力集中在中后段 —— 而那一段本来就被适当性门槛挡在外面。
   **在全池上显著的因子，未必在你实际会买的那一段上显著。**
2. **动量是这套权重里最站不住的 25%。** 三个市场的 IC 全为负。但改它需要这次回测**没见过**的
   日期：删掉一个在本样本上表现差的因子，和按本样本挑因子，是同一件事的两种说法。
3. **规模因子在 A 股显著为负（t = −2.11）。** 这不用修 —— 大市值偏好本来就是为适当性和流动性
   设的，不是为收益。原来只是「我们知道这会牺牲一点收益」，现在这句话有数了。

## 这份回测看不见什么

1. **没有 point-in-time 基本面。** 只拿得到今天的市盈率、市净率、市值，历史值是拿今天的数
   沿价格序列倒推的。对规模和换手率成立（股本变化慢），对**价值因子就是前视偏差** ——
   它假设今天的盈利和净资产在当时就已知。上面价值因子的 IC 要当上限读。
   顺带说明了「house minus value」那一行为什么塌得最狠：塌掉的那部分里，有一块本就是偷看来的。
2. **幸存者偏差。** 候选池是**今天**的指数成分。跌出指数的名字不在里面。
   月均 +1.8% 这个绝对水平别当真；两种排序吃的是同一阵顺风，所以能比的只有它们的差。
3. **没有成本。** 佣金、点差、汇兑全没算。
4. **34 期。** 三年多一点。t = 0.5 这个量级的差异，本来就需要比这多得多的样本才谈得上结论。

前两条用免费数据源修不了，所以是写出来、而不是绕过去。它们决定了这份回测**最多**能证明什么：
足够否掉一个默认值，不足够立一个新公式。
